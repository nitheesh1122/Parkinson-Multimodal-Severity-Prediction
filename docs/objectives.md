# Objectives

## Primary Objectives

- Develop an Explainable AI-based Parkinson's Disease detection system using speech biomarkers.
- Optimize speech features using Recursive Feature Elimination (RFE) and XGBoost Feature Importance.
- Train an XGBoost classifier for accurate Parkinson's disease prediction.
- Apply SHAP Explainable AI to interpret model predictions.
- Generate an AI Decision Support Report containing prediction probability, confidence score, speech biomarker summary, and explainability results.

---

## Phase I Objectives

- Complete literature survey of recent speech-based Parkinson's Disease prediction models.
- Identify research gaps in existing studies.
- Analyze the Parkinson's Telemonitoring Dataset.
- Design the proposed methodology and system architecture.
- Prepare documentation, diagrams, and research paper draft.
